Run locally
Unzip the archive and open index.html in a browser. The configurator
works offline with no build step, dependencies, accounts, or API keys.

Host it yourself
Upload index.html, style.css, and app.js to the same directory on a
static host such as GitHub Pages, Netlify, or your own web server.
Keep their filenames and relative locations. Once published, open the
URL for that directory. The site has no server-side sign-in.

Edit it
index.html contains the page structure.
style.css controls layout and appearance.
app.js contains the option catalog, recommendation rules, and preview.
Prices, dimensions, and load targets are illustrative.
